使用说明

快速上手

  1. 顶部选择算法（AES / RSA）
  2. 填写带 * 的必填项（对照下表）
  3. 左侧输入文本，点「加密」或「解密」，结果在右侧

必填项对照

操作必填项要求
AES 加密 / 解密密钥16 / 24 / 32 字节（128 / 192 / 256 位）
AES（除 ECB 外）IV块模式 16 字节；GCM 推荐 12 字节
RSA 加密公钥PEM 格式（PKCS#1 / SPKI）
RSA 解密私钥PEM 格式（PKCS#1 / PKCS#8）

选项说明

  • 格式：密钥 / IV 文本的解读方式。UTF-8 按原文取字节；Hex / Base64 先解码再取字节
  • 模式：CBC 常规分组；ECB 无 IV，不推荐正式使用（仅联调）；CTR / CFB / OFB 流式（无填充）；GCM 带防篡改认证，最安全
  • 填充：PKCS7 通用默认；Zero 补零（原文以 0x00 结尾时会丢失）；NoPadding 需明文为 16 字节整倍数
  • 密文编码：加密输出格式，同时作为解密时的密文输入格式
  • 位数：仅影响「生成」按钮随机出的密钥 / 密钥对长度
  • OAEP 哈希：仅 OAEP 填充需要，须与对方约定一致

配置方案（右侧面板）

  • 输入方案名点「保存」，把当前全部参数（含密钥）存入本机，同名覆盖更新
  • 下拉选择方案即可整体回填；「删除」移除所选方案

安全说明

  • 全部计算在本机浏览器内完成，不上传任何数据
  • 方案中的密钥为明文本地存储，请勿在公用电脑保存
  • RSA 单次加密明文有长度上限（如 2048 位 PKCS#1 v1.5 约 245 字节），超长会明确提示
